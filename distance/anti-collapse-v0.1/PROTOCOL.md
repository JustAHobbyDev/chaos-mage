# Experiment D — Anti-collapse benchmark v0.1

Authorized scope: specification, construction, validity admission, preparation,
provider preflight, neutral-only anti-collapse measurement, result freeze, review,
publication and normal push to origin/main. Stop there. No grounding, B.2 continuation,
distance ranking, diversity, usefulness, retrieval, production integration or testing
naturally generated outputs. Existing experiments and source corpus remain unchanged.

## Research question and asymmetry

Can a gate reject valid transfers that only restate native target reasoning while
retaining even one material irreducible epistemic departure? CLEAR_COLLAPSE alone
rejects. SUFFICIENT_DEPARTURE and BORDERLINE_KEEP retain. No success percentage,
accuracy oracle, composite score or requirement for dramatic/multiple departures.

## Design and authoring boundary

24 primary designs: six historical target tasks/practitioners × four A/B/C/D levels.
Historical baselines constrain case design, never the reverse. Existing baseline
fields are preserved exactly; new ordinary-inference and next-action fields explicate
them. These are scoped hypotheses about practice, not verified practitioner consensus.
Baseline files were committed before source mappings. Source records are accepted,
unchanged instruments. Shared synthetic facts/affordances are identical within ladders;
availability is not nativeness and synthetic facts are not grounding evidence.

A is terminology-only; B formalization/borderline; C one added operational rule;
D coordinated departure. The operator manifest records intentions and adversary tags
only for coverage and later diagnostics, never judge context or ground truth. C spans
action, observable, inferential warrant, decomposition and next inquiry. One rule can
have inseparable consequences across fields; it need not change only one field.
Six exotic-framed A and twelve plain operational C/D designs are tagged adversaries.
Only their neutral procedures are measured; no causal source-framing effect is tested.

Each case has a source-framed five-field mapping and separately frozen six-field
neutral procedure. Framing is an explicit removable prefix; every operational sentence,
condition, limit and follow-up survives in corresponding fields. The operator audit
checks this textual correspondence and a ladder audit reviews the single added rule.
The same operator authors and audits; this is not independent semantic validation.
No judge generates a paraphrase. No results-informed edits or replacements are allowed.

## Judge boundaries and contracts

Validity receives the unchanged v0.3 classifier, canonical schema, source, mapping and
target evidence. Anti-collapse receives only an opaque ID, target/evidence, exact fixed
baseline bytes and source-neutral procedure. Source names, source imagery, operator
metadata, historical labels, validity outputs and other judgments are excluded.
Both families receive byte-identical substantive packets. A strict allowlist constructs
packets; canonical local schemas reject additional fields and definite contradictions.
Provider wire schemas remove only schema identifiers and cross-field allOf constraints;
all returned responses undergo full canonical validation without repair.

The anti-collapse response includes three statuses, five independent categorical loci,
materiality, closest native reduction and losses, formalization and any new epistemic
constraint, decisive reason and uncertainty. Uncertain combinations can be explained;
definite lossless reduction cannot coexist with sufficient departure, and definite
irreducible/material departure cannot coexist with clear collapse. All-absent loci
cannot justify sufficient departure. No field counting or numeric novelty score.
