# Common-evidence comparative epistemic displacement

Assess only the supplied pair, fixed task, ordinary-practice baseline and shared
starting state. Both mappings have exactly the same evidence, affordances and
resource budget. Do not construct, repair, or reassess validity of mappings. Do not
browse, call external tools, retrieve context, or use other judgments. Source
identity and unusual vocabulary are not evidence of displacement.

Displacement means a change from ordinary target inquiry in representing, acting,
observing, inferring and choosing what to investigate next. It is not usefulness,
confidence in the target answer, difficulty, number of steps, or source prestige.
Do not invent a narrower baseline or lend one branch an unobserved result. Shared
capability/calibration facts establish affordances; they do not disclose future
outcomes. A mapping's signal and inference fields describe possible signals and
bounded warrants, not promises that a favorable result will occur.

If stage is prospective: compare operation choice, anticipated kinds of evidence,
warrants, decomposition and expected inquiry trajectory. Realized outcomes are
not supplied. Do not assume success, discriminating results, or full budget use.

If stage is consequence: compare the supplied simulated operations and realized
observations, what they license, which hypotheses change and what follows. Both
branches start at the identical state and operate in the same underlying world.
An uninformative result can legitimately limit consequential displacement. Do not
invent additional trials or future results. Later proposed inquiries are proposals,
not actions already performed inside the stipulated budget.

First decide whether the mappings differ meaningfully in epistemic departure:
- yes: at least one material difference, including material opposing advantages;
- no: differences do not establish materially different displacement;
- uncertain: the supplied information cannot support that decision; identify what
  is missing, rather than using uncertainty merely because comparison is difficult.

Compare five criteria separately. Each returns A, B, balanced or indeterminate
with a rationale addressing both mappings against the baseline:
1. action: which more substantially changes what the practitioner does?
2. observables: which more substantially changes what counts as meaningful evidence?
3. inferential_warrant: which more substantially changes why evidence supports a conclusion?
4. problem_decomposition: which more substantially changes operationally meaningful parts or relations?
5. inquiry_trajectory: which more substantially changes what is investigated next?

Also return four comparative diagnostics using those same relations:
- local_depth: which produces the deeper departure at its most changed point?
- inquiry_propagation: which propagates its epistemic change through more steps
  inside this stipulated investigation?
- task_reach: which altered reasoning governs more of the complete target task,
  including task portions left unresolved by this bounded investigation?
- native_reducibility: which is harder to translate back into ordinary target
  practice without losing an operationally important distinction?
Balanced is no meaningful advantage on that comparison; indeterminate means
insufficient information. These are pairwise relations, never intrinsic ratings.

Return exactly one overall relation:
- A_dominates: A has at least one materially greater epistemic departure, and B
  has no countervailing displacement advantage of comparable importance.
- B_dominates: the symmetric condition.
- tradeoff: each has a material advantage in different consequential respects,
  with no principled supplied basis for collapsing them into a winner. This is
  not mere difficulty, uncertainty, equal displacement, or any tiny opposing edge.
- approximately_equal: no meaningful comparative displacement difference is
  established, even if mechanisms or vocabulary differ.
- insufficient_information: a defensible comparison needs missing information.

Enforce: meaningful_difference no -> approximately_equal; uncertain ->
insufficient_information; yes -> A_dominates, B_dominates, or tradeoff. A genuine
local-depth versus task-reach conflict belongs under yes/tradeoff, not no/equality.

Explain the most important difference and explicitly address local depth, inquiry
propagation, task reach and native reducibility in decisive_basis. Explain why any
opposing advantages are comparable or not. One central difference can decide the
comparison. Never count criterion wins, average categories, assign weights, or
produce a numerical composite. Return confidence clear or close and an uncertainty
list; insufficiency must name missing information. Return only the required JSON.
