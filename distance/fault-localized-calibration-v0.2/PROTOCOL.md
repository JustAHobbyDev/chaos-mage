## Authoring and mandatory gates

Planned corpus: four primary mechanisms (Analysis of Competing Hypotheses,
Step-response probing, Chain-of-custody verification, Delta debugging), each with
local/scope/core variants, plus four controls: differential-diagnosis mechanism
death, crossdating generic remainder, ACH mechanism uncertainty, step-response
target uncertainty. Exactly 16 final cases, only after authoring gates pass.
Use existing accepted source instruments; never extract new ones.

Freeze targets.json before authoring variants. Bounded targets are legitimate
subproblems of the benchmark domain, never questions invented to make a bridge
fatal. All three variants share the exact target. Record narrowing and treat it
as a possible calibration confound. Local/scope must retain meaningful room for
substantial/reduced contributions to that target.

For each primary mechanism use one focal object and common graph: a central claim,
two material branch claims/actions, and a reporting leaf with no material descendant.
Hold source, target, state, operation, signal, limits, execution assumptions, four
inference slots and their order, branch count and action count fixed. Change only
minimal warrant-bearing text at the selected slot. Preserve comparable prose.
One intended unsupported claim per primary case is the authoring expectation.
Audit every field for additional explicit inference claims.

Before freezing final cases, delete the intended central claim. If any already
present or directly entailed source-derived material answer to the exact bounded
target survives, the candidate is NOT a valid CORE calibration case. Redesign before
freezing. Test direct descendants and conditional descendants; a hidden graph cannot
make a textual inference depend on a premise it does not require. Do not suppress
legitimate weaker inferences by redefining materiality or by an artificial target.

Use exact contiguous atomic spans with field, full parent, offsets, local context
and antecedents. Verify deletion cannot remove a neighboring claim's necessary
predicate. Retain all measured extra defects; never change inputs after measurement.

Record Unicode code-point length, token estimate ceil(character_count / 4) (a
transparent approximation, NOT a provider token count), and fraction of the newline-
joined five mapping fields. Require within-triple max/min character length <=1.10,
each position shortest in at least one triple, and alternate/tied fourth ordering.
No meaningless padding. Same focal identity, observation/operation/action ownership,
source, target, operations, signals, limits and graph topology are mandatory.
Semantic audits supplement exact field comparisons; metadata booleans are not proof.
If natural authoring cannot satisfy these gates, stop before provider measurement,
preserve concrete drafts and the failed audit, and report the design issue. Failed
authoring drafts are not final cases or scientific observations.

## Blinding, observations and freezes

Final case/claim IDs are random opaque identifiers. Hidden design records semantic
positions, focal identity, graph nodes/edges, direct/transitive dependents, expected
survivors/failures, mechanism/target/remainder hypotheses and confound metrics. None
of these enters provider packets. No cross-case, historical judgment, author intent,
expected status, role-labelled slots or review results reach the judge.

One fresh GPT-6 Astra/high claim measurement per extracted inference using unchanged
H warrant rubric. All claim judgments complete and commit before ablation packet
construction. Cases with zero UNSUPPORTED claims have no ablation/status. For eligible
cases delete every measured UNSUPPORTED span simultaneously with exact markers.
Do not delete conditional/uncertain claims, run subsets, substitute text or repair.
One fresh Astra/high artifact judgment per eligible case, using unchanged H scoring,
schema and packet instructions. Hidden design is a hypothesis, not a truth label.

Commit sequence: protocol/scoring/targets; primary cases/graphs/audits; controls;
claim inventory/packets; claim preflight; all claim results; ablation packets;
ablation preflight; all artifact results; operator audit; completion/report.
No provider request before relevant scientific inputs and preflight are committed.

Use H's pinned CLI 0.157.1 and executable hashes, model gpt-6-astra/high, fresh empty
isolated working directory, ignored config/rules, disabled tools/project context,
filtered environment, 900-second timeout, sequential requests and no harness retries.
No provider probes, model substitution, duplicate samples or additional review model.
Preserve original raw events, outputs, process/session provenance and usage. An
unavailable served model snapshot stays null. Detach scheduler from terminal and use
unique append-only reservations; never restart a reserved/sent observation.

Apply docs/EXPERIMENT-RECOVERY-POLICY.md. Unknown impact pauses investigation; known
non-contaminating engineering failures may recover only with preserved evidence and
committed positive proof. Never repair, replace or retry a scientific observation.
No terminal state auto-clears. Preserve historical tracked/runtime bytes and run
read-only preservation verifiers before each stage/resumed segment. Do not launch
old experiment measurements. H/G/F/E and production remain unchanged.

## Review and reporting

After all provider results freeze, the implementing operator separately checks:
intended warrant failure; omitted surviving contribution; invented dependency;
overlooked explicit dependency; operations-only survival reasoning; exact surviving
strongest-inference citation. Record STRUCTURALLY_CONCORDANT, PLAUSIBLE_ALTERNATIVE,
CASE_DESIGN_PROBLEM, JUDGE_DEPENDENCY_ERROR or AMBIGUOUS. This is a post-freeze design/
interpretation audit, not independent-rater evidence. Never rewrite model judgments
or hidden design to resolve a disagreement.

Report planned versus realized design, checkpoints, exact rubric hashes, target
narrowing, focal/length audits, all claim and artifact distributions, special states,
primary/control outcomes, citations/no-repair findings, and negative findings. Assess
measured deletion volume as well as intended lengths; extra measured defects may
break balance. No accuracy threshold or natural-output prevalence claim.

If a premeasurement gate fails, report an incomplete design-stage stop with zero
provider observations, not a scientific negative result. A failed draft does not
prove every possible construction impossible. Publish evidence without calling the
16-case experiment complete. Push only H.1, verify remote SHA, and stop. Do not
execute recommendations, merge main, resume E, rerun G/F, run natural-output admission,
qualify another model or integrate production behavior.
