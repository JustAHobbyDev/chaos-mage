# Experiment E — Natural-output anti-collapse v0.1

Authorized: fixed natural generation, freeze, blind neutralization, independent audit,
unchanged validity admission, unchanged anti-collapse measurement, freeze, review,
publication and normal push to origin/main. Stop after E. No distance ranking,
grounding, diversity, usefulness scoring, retrieval integration or production change.

## Frozen design

Thirty assignments, six unchanged Experiment D baselines, all fourteen accepted
instruments, fifteen generations from each requested family. Every source occurs two
or three times and in both families. operator-manifest.json fixes the assignments;
execution-orders fixes independent seeded schedules. No duplicate controls or output
selection. Generation receives only target, baseline and accepted instrument. D's
synthetic evidence fixtures are not reused. Downstream target.evidence is empty;
generated assumptions never become independently supplied facts.

The five-field mapping is the assessment unit. Explanation is retained separately for
post-freeze review and cannot add operative content to the assessment. Source records
and all old experiments remain unchanged. Baselines are scoped hypotheses about
practice, not practitioner consensus. No operator novelty labels before result freeze.

## Boundaries and stages

1. Commit preparation: baselines, source assignments, generation inputs, schemas,
   prompts, code, tests, configuration, schedules and preservation inventory.
2. Run and commit artificial generation probes; collect and freeze all generations.
3. Commit neutralizer packets from frozen successful mappings; run and commit probes;
   collect cross-family neutralizations; freeze and commit before audit.
4. Commit audit packets; run and commit probes; collect two independent audits per
   compliant paraphrase and freeze/commit them. Both must pass, including all checks.
5. Commit unchanged-validity packets for all successful original mappings, including
   neutralization exclusions; run and commit probes; collect/freeze both families.
   Derive and commit admission before any anti-collapse call.
6. Primary admission requires generation success, compliant neutralization, both
   audits passing, and unconditional Valid/Valid. If fewer than eighteen cases or five
   targets survive, publish insufficient natural-output coverage and stop measurement.
7. Commit neutral-only packets; run and commit anti-collapse probes; collect/freeze
   both families and commit before examining outcomes for qualitative review.
8. Recompute metrics, review all cases, verify, publish and normally push main.

Each next-stage packet is constructed mechanically after its upstream freeze. No
stage inspects downstream judgments. Each launch verifies committed input hashes and
the upstream commit. Filter frozen schedules without reshuffling or supplementation.
Original payloads are immutable; public files reproduce retained response bytes.

Neutralizer receives only opaque ID, target question and five-field mapping. Auditor
receives those plus the paraphrase, with no baseline or model/source metadata.
Validity receives canonical source, target and original mapping only. Anti-collapse
receives opaque ID, target, exact fixed baseline and the seven neutral procedure
fields, with no source identity, original mapping, provenance metadata or judgments.
The only input-schema extension relative to D is explicit neutralization limits.
Both classifiers and validity/anti-collapse response schemas remain byte-identical.

## Isolation and failure policy

Use the exact requested models and recorded CLI versions in execution-config.json.
One process at a time, 900-second timeout, fresh process/session, empty working
directory, no repository/rules, memory, tools, retrieval, browsing, hooks, plugins or
connectors. Native structured-output machinery alone is allowed. Existing subscription
authentication is consumed without copying or retrieving credentials. No SSH planned;
kte-ssh-accept must succeed before any SSH if circumstances change.

Each of five stages has two artificial schema/isolation probes, committed before
measurement. Up to 250 calls including probes. Unknown served model IDs and snapshots
remain unknown. Audit exposed formatter retries separately from harness retries.

The user's planning decision explicitly permits content attrition: schema-invalid or
self-labeled generations, schema-invalid or evaluative neutralizations, and completed
audits finding loss are preserved exclusions; scheduling continues. No regeneration,
repair, retry or replacement. Provider/transport/timeout errors, isolation violations,
unexpected models, and malformed audit/validity/anti-collapse judgments halt scheduling.
Probe failures always halt. Freeze partial evidence; any recovery requires explicit
recorded authorization. Content exclusion requires independently successful provider
and isolation auditing. A missing/unsuccessful provider result is a fatal failure.

The wording detector uses case-insensitive word/phrase matching, whitespace/hyphen
normalization, and the explicit NEUTRALIZER ban. Additional semantic evaluative
language is checked by both auditors. Generation self-label checks reject explicit
novelty/verdict vocabulary, not ordinary operational words such as new or different.
Literal wording bans can exclude innocuous phrasing; report this limitation.

## Analysis and publication

Only CLEAR_COLLAPSE rejects; SUFFICIENT_DEPARTURE and BORDERLINE_KEEP keep. No pooled
family verdict, novelty score, ranking or success threshold. Compute counts with
explicit denominators and null fractions when empty. Report each attrition category
separately, including validity outcomes for neutralization-excluded generations.

Report status distributions, status and keep/reject agreement, five loci separately,
materiality, lossless native reduction and formalization agreement. Describe generator,
source and target patterns without ranking or causal attribution. Source assignment is
purposive, not representative; generator and neutralizer family are coupled.

Post-freeze review covers all cases and every rejection by either family, borderline,
status disagreement and same-status mechanism disagreement. Identify formalization and
one-rule cases only then. Review retained procedures for native restatements. Review
against the original mapping as well as the paraphrase to distinguish gate suppression
from neutralization loss. Audit agreement is not proof of fidelity or correctness.

Publish all 26 handoff report items with checkpoint ancestry and result binding. Use
the containing publication commit title for its own SHA, then report the resolved SHA
externally. Run all 216 historical tests and all historical public/private verifiers,
new tests, metric recomputation, historical hash checks and git diff --check. Push
normally; stop on push failure; verify HEAD equals remote main. Recommend but do not
execute subsequent research.
