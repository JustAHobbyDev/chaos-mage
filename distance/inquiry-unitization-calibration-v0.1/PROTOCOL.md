# H.4 protocol — frozen before measurement

Base 8f488b3b02973370e26fd970a5fd5a8d56e8bec6 on experiment-h3-negative-remainders.
Publish only experiment-h4-inquiry-unitization. No main merge.

Freeze rule/schema, 12 primary cases (four mechanisms × negative/affirmative/distributed),
six controls, two offline H.3 fixtures, deterministic extractor/tests, packets/preflight,
then 18 fresh sequential GPT-6 Astra/high assessments, then coverage and report.
No other provider, duplicate sample, calibration probe or artifact viability judgment.
Historical H.3 outputs and runtime remain immutable. Recommendation is not execution.

The authoring gate must pass deterministically before any provider request. It verifies
all intended structures, exact citations, canonical triplet equality, six control
boundaries, regression coverage, all-field scanning and polarity invariance. The
extractor is a bounded grammar for this authored corpus and the two fixtures, not a
claim of open-language semantic completeness. It does not read case IDs, expectations,
negative flags or model outputs. Ambiguous/unrecognized content is not invented.
No rule, case, grammar, schema, packet or execution configuration changes after launch.

Packets contain only the frozen rule, response instructions, schema contract and one
surviving mapping plus descriptive metadata. Hidden expectations and deterministic
extraction results are withheld. The model populates components and assesses role;
the validator independently rediscovers units and forces the invariant by rejection,
never by repairing the response. Missing, wrong and duplicate role assessments remain
observed failures. A structurally parseable scientific failure is recorded and the
remaining distinct cases are measured; failed cases cannot feed productivity/success
aggregation. Transport errors, tool use, model substitution, invalid JSON/schema or
uncertain execution status terminate measurement with no retry. Recovery follows
../../docs/EXPERIMENT-RECOVERY-POLICY.md; engineering recovery requires positive proof
of unchanged scientific inputs, configuration, context and response.

Every attempt has an exclusive reservation, frozen packet/schema/config hashes, input
commit, command, empty temporary cwd, fresh ephemeral session, raw events, raw response
and validation. Provider overrides and parent session markers are removed; existing
auth only. No network/tool access by the judge. CLI and native executable hashes are
checked. No harness retries. Unexposed provider retries and unavailable served snapshot
identifiers remain unknown. All sent observations are retained without replacement.

No numerical accuracy threshold. Report every invariant violation and systematic pattern.
The duplicate control expects one complete unit from two independent textual bundles;
the other five controls are incomplete. Primary total=12; calibration complete total=13.
Counterfactual/productivity fields remain for continuity, but no artifact viability is run.
