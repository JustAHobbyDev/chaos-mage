## Question and boundaries

After deleting unsupported local claims, is there a warranted, source-derived,
target-relevant, productive, material contribution? False rejection of distinctive
transfer is costly. Admission is permissive; no ranking, usefulness/quality/creativity
scoring, production integration, new instruments, other models or duplicated judgments.
No expected artifact labels or planted defects. Natural generator instruction is an
adaptation of the repository's ordinary operational-transfer instruction without the
old baseline/explanation fields. All operative content uses the five-field instrument.

## Isolation, identity and provider failures

Only requested gpt-6-astra, model_reasoning_effort high. Codex 0.157.1 executable and
native binary hash-bound as in H.4. Empty temporary cwd per invocation, ephemeral,
ignore user configuration/rules, no project docs, tools, memory, web, apps, plugins,
hooks or other packets. Existing auth is consumed by CLI without retrieving secrets.
No generation history reaches evaluation beyond frozen mapping; generation never
receives evaluations. Only prompt and schema reach each model through the interface.
Up to six independent processes, one packet in each. Native output-schema handling
is allowed. There are no harness retries, probes or duplicate scientific judgments.
Expose model metadata where available; unknown served identifiers/snapshots are null.
CLIs/provider may have unobservable internal retries: disclose, never claim none.

A timeout, transport/CLI failure, malformed JSON, duplicate JSON keys, schema-invalid
response, unexpected model, session reuse or tool activity is preserved and terminates
measurement scheduling under the provider-failure policy. In-flight calls are preserved;
no new call launches after a failure is observed. No retries/replacements. Successfully
parsed but semantically bad citations, claim/inquiry coverage and invalid scientific
reasoning are observations, recorded as diagnostics rather than engineering exceptions.
Parsing bugs may be recovered only with positive raw-byte/input/context non-contamination
evidence under docs/EXPERIMENT-RECOVERY-POLICY.md. No scientific output repair.

Before each stage and launch verify frozen/historical hashes, checkpoint and clean
continuation. Append-only state/reservation/raw evidence in .runtime, published unchanged
at stage freeze. Any invariant violation pauses; terminal measurement/lineage state
cannot auto-resume. Committed immutable packets and upstream freezes define allowlists.
Freeze checkpoints between stages. No recommendation is executed after H.6.
