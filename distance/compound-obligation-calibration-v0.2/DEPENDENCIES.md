# Origin-sensitive direct dependencies

Every direct material dependency receives content_origin, epistemic_function, assertion_mode, origin_refs and rationale. Use the same independent origin/function definitions as Stage A, with ORIGIN_UNCERTAIN and FUNCTION_UNCERTAIN retained explicitly. Citation roles are an independent third concept.

Order: classify origin; classify function; classify REFERENCED_PREMISE versus ASSERTED_COMPONENT; select resolution; freeze the complete classification/discovery response; only then mechanically derive contracts. EMBEDDED_FACT -> FACT_WARRANT without origin classification is forbidden.

GROUNDING_REF is only a supplied proposition merely invoked at the same scope and strength, without reassertion, transformation or extension. Record positive target/source origin references and a scope-preservation rationale. It creates no scientific obligation. A generated or expanded assertion cannot use this path. Referencing an agreed policy threshold alone creates no factual warrant; asserting that harm begins there is generated substantive content.

CLAIM_REF points to another frozen evaluated claim and reuses its overall result without a duplicate scientific call. Prefer an existing claim over an inline duplicate. Reject cycles. Excluded/unmeasured references prevent clean acceptance.

INLINE_OBLIGATION is material, separately unevaluated substantive content asserted by this compound claim. Supplied asserted components route to TARGET_FIDELITY, SOURCE_FIDELITY, or both. Generated components route FACT -> FACT_WARRANT; INFERENCE -> DERIVED_WARRANT; CONDITIONAL_RELATION -> CONDITIONAL_LICENSE; OPERATION -> OPERATION_LICENSE; GOVERNANCE_RULE -> GOVERNANCE_STRUCTURE; LIMIT -> LIMIT_WARRANT.

Materiality: could the primary claim still be accepted at essentially the same meaning/scope if this content were false, unjustified or removed? If no, it is material. Ordinary stop/pause/continue/rollback to the prior safe state alone does not require an operation judgment. Substantive diagnostics, comparisons, interventions, target modifications, empirical reasons, and discrimination relations require their own material dependency records. A normative number is not alone an empirical claim.

One level only. Direct peers are allowed. A secondary requiring a further distinct substantive level makes SPLIT_REQUIRED. Preserve ambiguous referents explicitly, without guessed contracts. Uncertain closure constrains aggregation to at least UNCERTAIN unless VIOLATED; missing provider observations remain incomplete, not manufactured verdicts.

Every base and inline obligation freezes its own obligation_id, contract, subject and provenance_refs before Stage C. References have semantically irrelevant array order, unique source IDs and material SUPPORT/CONTEXT roles. No parent-role inheritance, fallback, inferred role, or citation reconstruction is allowed during projection.
