# Classification v0.1

Content origin and epistemic function are independent axes. H.5 SUPPORT/CONTEXT
citation provenance is a third concept. No origin implies a function or vice versa.
All four origins crossed with all six functions are valid schema combinations.
See taxonomy.json for the frozen definitions and schemas/classification.schema.json
for the exact record. No old seven-role labels are used.

Assignment order: check atomicity; assign origin independently; freeze that choice;
assign function independently; freeze that choice; only afterward derive obligations.
Stage A returns those choices in that order in a single isolated response and asks
no validity or contract questions. Whole-stage freezing precedes Stage B.

ATOMIC permits one primary assertion with subordinate premises/actions. Independent
co-primary assertions require SPLIT_REQUIRED, as does downstream discovery requiring
another level of substantive obligations. Do not re-atomize a measured claim.
Uncertain axes retain null kind and alternatives/rationale. No forced assignment.
SPLIT_REQUIRED and uncertain assignments do not enter obligation measurement.

Absent positive supply evidence, MAPPING_GENERATED is the default unless genuinely
uncertain. Supplied provenance must name the corresponding input. BOTH requires
independent supply of the same proposition, not composition of two inputs.
Failed fidelity is CLASSIFICATION_CONTRACT_FAILURE; no post-evaluation reclassification.
