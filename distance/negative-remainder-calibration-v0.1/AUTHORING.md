# Frozen triplet authoring protocol

Four instruments and exact questions are fixed in targets.json before case authoring.
For each mechanism, reuse state, baseline operation, observation-container description,
execution conditions and generic limits verbatim. Each member has one common intended
unsupported conclusion plus one focal negative consequence. Place the focal consequence
once in the mapping, without independently duplicating its decisive relation elsewhere.
Use a single comparative observation, an unresolved contrast with a named discriminating
operation, or a specific account of why the record does not establish the target answer.

The comparative record's contents must differ to license different consequences; this
is an authored boundary calibration, not an intervention on wording alone. Record those
differences and measure text lengths/claim counts without padding to a numerical ratio.
Preserve equal baseline procedure/conditions and similar epistemic care. Composite
inquiry content is inventoried as separate atomic assertions with shared parent context;
its connected inquiry consequence may cite multiple exact spans. Never delete its
premises merely because the inquiry is evaluated counterfactually.

Search every mapping unit, not just inference and signal. Distinguish stipulated context,
already executable generic procedures, observations, explicit claims and source-specific
inquiry decisions. Audit intended ablation using exact spans. Record all negative
candidates and other potentially productive contributions, including direct entailments.
The role gate compares authored evidence to the removal effects; intended labels alone
cannot establish passage. Review the resulting readable cases before recording passage.

Controls use crossdating (insufficiency wording with an actual bound), delta debugging
(detailed but nondiagnostic oracle jargon) and differential diagnosis (terse inquiry
with an explicit outcome relation). All controls pass the same semantic gate.

No scientific input revision after measurement starts. A measured unexpected claim status
is an observation, not permission to redesign. Freeze the measured all-field candidate
inventory separately from the hidden authoring audit before artifact measurement.
