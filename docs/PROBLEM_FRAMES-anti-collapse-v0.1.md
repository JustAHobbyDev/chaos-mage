# Problem Frames — Experiment D

## Entry #1 — 2026-09-28 — Anti-collapse benchmark

### Domains

Read-only lexical domains: historical experiments and accepted source instruments.
Experiment-owned lexical domains: six fixed baselines, authored mappings, neutral
paraphrases, operator audits, isolated judge packets, schedules and immutable results.
The biddable operator authors and reviews; two external model services return variable
judgments through causal CLI interfaces. Existing subscription authentication is used
without retrieving credentials. Only packets and fixed instructions cross the judge
boundary; sources reach validity judges, but not anti-collapse judges. Neither receives
operator intentions, other results, repository access or tools.

### Frame split

Preparation transforms authored inputs into frozen lexical packets. Commanded
measurement collects independent validity and anti-collapse judgments. Post-freeze
transformation and research review describe the collected evidence without adjudication.

### Requirements (per frame, with explicit out-of-scope)

Preparation must preserve the historical baseline scopes, all meaningful operations in
neutralization, and one-rule C designs across five loci. Measurement admits only
Valid/Valid transfers and treats uncertainty permissively: only CLEAR_COLLAPSE rejects.
Review must expose suppression of C/D designs and retained A designs without treating
operator intent as truth. No distance ranking, grounding, diversity, usefulness,
retrieval, natural-output experiment or production gate is in scope.

### Invariance test

Hashes and Git ancestry fix local inputs, not practitioner norms or model internals.
Baselines remain scoped hypotheses; availability is tested by artificial probes after
preparation. Preserve requested/returned metadata and unknown backend identity. Single
observations measure this corpus, not universal correctness or within-family reliability.

### Stakeholder test

Chaos Mage generates unorthodox reasoning; false rejection is costly. The researcher
needs inspectable independent evidence, not repaired answers or a ranking between
accepted generations. Fresh stateless judgments and permissive uncertainty serve these
stakeholders. No borrowed product-origin analogy supplies an additional assumption.

### Open questions — decided here, with reasoning

- User confirmed: historical/native baselines constrain cases, never the reverse.
- Neutral-only protocol; terminology-bias causality is unmeasured.
- A single new operational rule can have coupled consequences across judgment fields.
- Use two requested model families, sequential isolated calls, no harness retry/repair.
- Freeze everything before provider probes; exclude failed validity without replacement.
- Insufficient coverage or measurement failure freezes evidence and stops scheduling.
- User authorizes specification through normal push; no extra approval stage is added.

### Carried forward

Authoring bias, baseline uncertainty, model thresholds and opaque served snapshots remain
limitations. Stop after this benchmark's publication; recommendations are not executed.
