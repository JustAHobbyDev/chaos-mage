# Model capability qualification

## Entry #1 — 2026-09-29 — Capability rather than interchangeability
### Domains
Historical D/E packets, classifiers, schemas, freeze records, and responses are
independently authored lexical domains, read-only. The operator controls scope and
recovery authority. Meta's external service controls availability and reasoning
behavior. The machine owns qualification copies, reservations, responses, and review.
Only the selected packet and schema cross to the model; credentials cross only the
authentication boundary. Historical outcomes never cross the measurement boundary.
### Frame split
Transformation verifies exact historical bytes and freezes a manifest. Commanded
behavior collects one isolated response per case. Post-freeze information display
and operator assessment diagnose capability rather than inter-model reproduction.
### Requirements (per frame, with explicit out-of-scope)
Resolve all twelve prescribed cases without substitution. Freeze principle, inputs,
configuration, and order before provider calls. Establish exact Contributor identity
and both contracts using artificial probes. Freeze all responses before historical
comparison. No fresh Astra/Fable, F execution/design changes, E resumption, new
mappings, natural-output anti-collapse, retrieval, grounding, filtering, or tuning.
### Invariance test
Git content and hashes establish stable observable inputs. Provider availability and
served weights can change; current catalog and returned metadata bound claims to
this run. Twelve cases cannot establish universal competence or model equivalence.
### Stakeholder test
The reused D/E contracts serve the same operator and stateless research judges.
The previous bridge's paired fresh Fable/Muse comparison served a different decision;
its agreement criteria and provider scheduling are not carried forward.
### Open questions — decided here, with reasoning
Missing case, unavailable exact model, failed authentication/schema, or measurement
failure stops scheduling with retained evidence and no automatic recovery. Only an
environment credential is authorized initially. Historical projections preserve fields,
enums, required structure, and null semantics; full canonical validation follows
decoding. Partial or unavailable evidence means inconclusive, not a failed model.
### Carried forward
The handoff authorizes freeze through ordinary push. Inspectable rationale is not
access to private model internals. Cross-model disagreement requires classification
as specification ambiguity, legitimate reasoning variation, or model failure.
