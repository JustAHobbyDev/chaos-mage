# Family-B instrumentation bridge

## Entry #1 — 2026-09-29 — Frozen instrument, new provider
### Domains
The independently authored historical corpus, classifiers, schemas, and prior responses
are lexical and read-only. The operator supplies scope and stopping authority (biddable).
Fable's subscription service and Meta's Contributor API are external services whose
availability and model behavior can change. The bridge owns copied packets, schedule,
request metadata, responses, and review artifacts. Credentials cross only the local
adapter/authentication boundary, never the judge prompt or published evidence.
### Frame split
Transformation preserves exact historical packet bytes and derives provenance. Commanded
behavior collects isolated provider responses under a frozen schedule. A later information
display and qualitative review describes differences between instruments.
### Requirements (per frame, with explicit out-of-scope)
Exactly the prescribed twelve cases must resolve to frozen measurements. Each provider
receives the same substantive bytes and unchanged canonical contract. At most one primary
call per case/provider is permitted; any failure stops scheduling. Review requires all
24 responses committed first. Fable is no ground truth. No third judge, prospective
validity, Experiment F, resumed E, new natural anti-collapse, retrieval, or grounding.
### Invariance test
Historical bytes are stable and observable through Git and measurement hashes. Serving
behavior is a moving domain: catalog discovery and artificial preflight establish only
current availability, while returned identifiers are preserved without claiming immutable
weights. The bridge cannot establish general model equivalence or future reliability.
### Stakeholder test
The reused D/E harness was written for this project's operator and isolated research
judges. Its no-tools/fresh-session constraints fit this use. A direct stateless API adds
no agent workspace or memory; provider-native formatting remains permissible.
### Open questions — decided here, with reasoning
Missing cases or unavailable exact models stop the bridge, with no substitution. Partial
evidence is frozen as inconclusive. Use historical structural wire projections, enforce
canonical schemas locally, and keep all fields/enums/null alternatives. Two artificial
contract probes per provider minimize scarce subscription use. No retries, tuning, or
semantic repair. Existing explicit handoff authorizes preparation through ordinary push.
### Carried forward
Review must distinguish functional disagreement from encoding and gate effects. Provider
internals and immutable served snapshots may remain unobservable and must be stated.
